Personal Library Manager

سامانه مدیریت کتابخانه شخصی، نرم‌افزاری برای ثبت و مدیریت کتاب‌های شخصی است که به کاربران کمک می‌کند اطلاعات کتاب‌های خود را مرتب نگه دارند و وضعیت مطالعه آن‌ها را پیگیری کنند.

مشکل و نیاز اصلی

با زیاد شدن تعداد کتاب‌ها، پیدا کردن اطلاعات آن‌ها و به خاطر سپردن کتاب‌های خوانده‌شده و خوانده‌نشده دشوار می‌شود. این سامانه برای حل این مشکل طراحی شده است.

امکانات اصلی

- ثبت کتاب جدید
- مشاهده فهرست کتاب‌ها
- جست‌وجوی کتاب بر اساس عنوان یا نویسنده
- ویرایش اطلاعات کتاب
- حذف کتاب
- مشخص کردن وضعیت مطالعه کتاب

مخاطبان محصول

افرادی که می‌خواهند کتاب‌های شخصی خود را به‌صورت منظم مدیریت کنند.

فناوری‌های پیشنهادی

- زبان برنامه‌نویسی Python
- Git و GitHub برای مدیریت نسخه‌ها و نگهداری مستندات
