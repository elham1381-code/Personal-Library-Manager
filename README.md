# Personal-Library-Manager
بسیاری از افراد کتاب‌های زیادی دارند، اما ممکن است اطلاعات کتاب‌ها، وضعیت مطالعه و یادداشت‌های خود را به‌خوبی مدیریت نکنند. این سامانه با هدف ساده‌سازی مدیریت کتابخانه شخصی طراحی می‌شود.
امکانات‌ کتابخانه 
## افزودن کتاب جدید
ویرایش و حذف اطلاعات کتاب
جستجوی کتاب بر اساس عنوان و نویسنده
دسته‌بندی کتاب‌ها
مشخص‌کردن وضعیت مطالعه کتاب (خوانده‌نشده، در حال مطالعه، خوانده‌شده)
ثبت یادداشت برای کتاب‌ها
نمایش آمار کلی کتاب‌ها
## مخاطبان محصول
افرادی که به مطالعه علاقه دارند
دانشجویان و دانش‌آموزان
افرادی که می‌خواهند کتاب‌های شخصی خود را مدیریت کنند
