منشور پروژه (Project Charter)

۱. نام پروژه

Personal Library Manager (سامانه مدیریت کتابخانه شخصی)

۲. هدف پروژه

هدف این پروژه ساخت نرم‌افزاری ساده برای ثبت، جست‌وجو و مدیریت کتاب‌های شخصی و پیگیری وضعیت مطالعه آن‌هاست.

۳. محدوده پروژه

قابلیت‌های اصلی پروژه شامل موارد زیر است:

- افزودن کتاب
- مشاهده فهرست کتاب‌ها
- جست‌وجوی کتاب
- ویرایش و حذف اطلاعات کتاب
- تعیین وضعیت مطالعه کتاب

قابلیت‌هایی مانند اتصال به کتابخانه‌های آنلاین و ایجاد حساب کاربری در نسخه اولیه قرار ندارند.

۴. خروجی‌های پروژه

- مستندات تحلیل و برنامه‌ریزی
- طراحی اولیه سیستم
- برنامه قابل اجرا
- آزمایش قابلیت‌های اصلی
- راهنمای استفاده از نرم‌افزار

۵. مراحل انجام پروژه

۱. جمع‌آوری و تحلیل نیازمندی‌ها
۲. طراحی سیستم
۳. پیاده‌سازی
۴. آزمایش و رفع اشکال
۵. تکمیل مستندات و تحویل نهایی

۶. نقش‌ها و مسئولیت‌ها

توسعه‌دهنده پروژه مسئول تحلیل نیازمندی‌ها، طراحی، برنامه‌نویسی، آزمایش و مستندسازی است. پروژه در چارچوب درس مهندسی نرم‌افزار انجام می‌شود.

۷. معیارهای موفقیت

- امکان ثبت و مشاهده کتاب‌ها
- عملکرد صحیح جست‌وجو
- امکان ویرایش و حذف کتاب‌ها
- نمایش صحیح وضعیت مطالعه
- کامل بودن مستندات پروژه

۸. ریسک‌های احتمالی

- کمبود زمان برای تکمیل همه قابلیت‌ها
- بروز خطاهای برنامه‌نویسی
- دشواری در انتخاب روش ذخیره‌سازی اطلاعات

برای کاهش این ریسک‌ها، ابتدا قابلیت‌های اصلی پیاده‌سازی و سپس آزمایش می‌شوند.

۹. فرضیات پروژه

- زبان برنامه‌نویسی پیشنهادی Python است.
- قابلیت‌های نهایی در مرحله طراحی مشخص می‌شوند.
- پروژه باید در طول ترم تکمیل شود.
